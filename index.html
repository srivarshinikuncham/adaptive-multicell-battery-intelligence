How This Demonstration Relates to the Project

The browser simulator reproduces the decision logic used by the embedded battery-management demonstration: four cell values are evaluated, average and imbalance are calculated, the weakest and strongest cells are identified, and the system selects a health state and protection state. The physical project uses ESP32 inputs and Blynk telemetry; this public simulator provides an evaluator-friendly way to test the same core logic without requiring the evaluator to connect hardware.
